# 📘 Programação Modular  
Bem-vindo ao meu repositório! 🚀  
Sou **André Luiz** e aqui registro meu aprendizado na disciplina de *Programação Modular* da **PUC Minas**.  
Este espaço reúne exercícios e projetos desenvolvidos ao longo da matéria, organizados para acompanhar minha evolução e facilitar revisões futuras.

---

## 🎯 Objetivo
Este repositório tem como objetivo consolidar os conceitos de programação modular, com foco em:
- organização de código  
- reutilização de funções  
- boas práticas de desenvolvimento em Java  

---

## 🔖 Organização do Repositório  
Os conteúdos estão organizados em duas categorias principais:

- **exercicios/** → listas de exercícios propostas em aula  
  - `lista-00/`

- **provas/** → avaliações da disciplina, agrupadas por bimestre  
  - `prova-1/` → lista de revisão, prova teórica e prova prática do 1º bimestre  
  - `prova-2/` → lista de revisão, prova teórica e prova prática do 2º bimestre  

Essa organização permite acompanhar minha evolução ao longo da matéria.
